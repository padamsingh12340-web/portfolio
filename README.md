## ⚙️ Getting Started

1. Clone the repository:
   git clone https://github.com/padamsingh12340-web/portfolio.git
2. Open the project folder:
   cd portfolio
3. Open index.html in your browser. No build step or installation is required.

## 🌍 Deployment (GitHub Pages)

1. Go to Settings → Pages in your repository.
2. Under "Source", select the main branch and the / (root) folder.
3. Click Save. Your site will be live in a minute or two.
